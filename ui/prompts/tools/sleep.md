Suspend the agent loop for a specified number of seconds. The loop makes no model call and runs no tools while it waits, so a long wait costs no tokens — use this to impose a delay between actions, or to throttle rapid retries. Maximum duration is 1 hour (3600 seconds); 0 or a negative value is rejected — use start_tick for a periodic wakeup instead. The wait runs on the client side, and Stop (the user cancelling the run) ends it early: the result then says the sleep was interrupted instead of the full duration.
