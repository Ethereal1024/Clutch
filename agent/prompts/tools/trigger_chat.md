Run a shell command and wait for it to finish before the next step. CHAT MODE: only provably read-only commands are allowed — a static whitelist rejects anything that could write files or change state (see run_command for the list). Use trigger rather than run_command when the read-only command takes longer than about 30 seconds, so it is waited for instead of killed. Nothing happens in the loop while it runs: no tokens are spent waiting. The tool result is the command's output, and a non-zero exit is reported with its exit code. Stop cancels it. cwd is fixed to the workspace root; interactive commands are blocked.
