Read a file OR list a directory in the workspace (path relative to the workspace root). A directory returns its entry listing (subdirectories end with '/'). For a file, prefer the line-range form: pass offset (1-based start line) and limit (line count) to read only the slice you need — output is line-numbered and ends with a "(showing lines X-Y of N; use offset=Y+1 to continue)" hint when more remains. A range larger than the read budget returns an error; narrow the limit or use grep. Without offset/limit the whole file is read and truncated at max_chars (default $read_max_chars) with a "use offset=N to continue" hint — never re-read a file from the top, continue with that offset instead. Only read files relevant to the task; content-creation tasks do not need to explore the workspace.
