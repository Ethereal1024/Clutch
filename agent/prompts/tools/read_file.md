Read a file in the workspace. path is relative to the workspace root. Prefer the line-range form: pass offset (1-based start line) and limit (line count) to read only the slice you need — output is line-numbered and ends with a "(showing lines X-Y of N; use offset=Y+1 to continue)" hint when more remains. Without offset/limit the whole file is read and truncated at max_chars (default $read_max_chars). Only read files relevant to the task; content-creation tasks do not need to explore the workspace.
