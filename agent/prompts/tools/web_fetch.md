Fetch a web page by URL and return its readable text (title + body; scripts, styles and site chrome stripped). HTML pages and raw text/JSON responses both work; binary types are refused. max_chars caps the returned text (default $max) and start skips ahead in characters — when content is truncated the tail note gives the exact next start value. Non-public hosts (localhost, LAN IPs) are refused. Prefer 1-2 targeted fetches over many: search first with web_search, then fetch only the promising URLs.
