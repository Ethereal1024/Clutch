Search the web for information the workspace cannot answer: current events, library versions and release notes, error messages, docs pages. Returns ranked results (title, URL, snippet); follow up with web_fetch on the 1-2 most relevant URLs for the full text. query is the search string — engine syntax like quoted phrases, site: and -term filters work; short factual queries beat long sentences. max_results caps entries (default $max). Backends available on this machine ($backends) are tried in order — the first that returns results wins; when all fail the error lists each backend's reason, and backend=<name> pins one.
