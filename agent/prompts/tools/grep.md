Search files in the workspace for a regex pattern. Use this to locate code before reading files — it is cheaper than reading whole files or running grep in the shell. pattern is a Python-style regex (e.g. "def build_\\w+", "TODOs?"). path limits the search to a subdirectory or file (default: whole workspace); include filters by filename glob (e.g. "*.py", "*.md"). Hidden files and binary files are skipped. Output is capped at 100 hits as "path:  Line N: text"; narrow the pattern or path if the result is truncated. Workspace-relative paths returned here can be passed straight to read_file.
