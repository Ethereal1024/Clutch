Start a periodic ticker: every N seconds it appends a `[tick: every Ns, at <ISO time>]` user message to the log, then asks the loop to continue. The loop is NOT blocked — a step already in flight is never interrupted and reads the new message on its next turn, while with nothing in flight the message begins the next turn. Use this to poll for external state (a build finishing, a file appearing) without burning a blocking sleep. Only one ticker runs at a time: a second start_tick replaces the first interval. The minimum interval is 1 second and the maximum is 1 hour. The ticker belongs to this run and dies with it; stop it with end_tick.
