Run a shell command and return its output. CHAT MODE: only provably read-only commands are allowed — a static whitelist rejects anything that could write files or change state. Whitelisted examples: ls, cat, grep, find, pwd, whoami, id, uname, date, echo, printf, which, df, du, free, uptime, ps, lsusb, lspci, lscpu, dmesg, nvidia-smi, ip, ss, ping, hostname, head, tail, wc, sort, uniq, diff, stat, file, git status/log/diff, sed without -i, curl without -o. Never attempt mutating commands (rm, mv, touch, mkdir, git commit, python3 script.py, ...) — they are rejected. cwd is fixed to the workspace root. Interactive commands are blocked (bare python, vi, vim, less).
